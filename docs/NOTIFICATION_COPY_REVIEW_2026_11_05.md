No notification copy or scheduling changes implemented. The earlier editorial proposal below is retained only as review history.

## Proposed timing titles

| State          | Arabic                            | English                 |
| -------------- | --------------------------------- | ----------------------- |
| Advance prayer | `بقي {minutes} على صلاة {prayer}` | `{prayer} in {minutes}` |
| At prayer time | `حان وقت صلاة {prayer}`           | `Time for {prayer}`     |
| Example        | `بقي ١٥ دقيقة على صلاة العشاء`    | `Isha in 15 minutes`    |

`{minutes}` means a fully localized duration, including its unit: `٥ دقائق` / `١٥ دقيقة`, and `5 minutes` / `15 minutes`. Keep the supported 0/5/10/15/20/30 choices; zero uses the at-time title. Do not repeat the duration in the body. These are proposed notification titles, not changes to the existing setting labels.
