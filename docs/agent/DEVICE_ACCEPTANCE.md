# Physical-device acceptance

Status: pending human/device execution. Automated viewport emulation, axe and keyboard checks do not establish screen-reader or OEM acceptance. Record device model, OS, browser/app build, locale, date, reviewer, result and linked evidence for each journey.

Final-touch downloads: on a real device start a page/juz pack and an audio collection, navigate within the app, return and cancel. Verify recorded voices, truthful bytes/readiness, verified-file resume after reload and ZIP cancellation focus. Test backgrounding, suspension and process death separately; the document session guarantees only in-app navigation continuity. Native persistent-file storage remains the separate Android migration, not a completed acceptance result.

- Android TalkBack, Arabic and English: Home next action → Reader count/save → return/reload → Settings reminder readiness → test notification → backup export. Confirm complete accessible names, logical order, no focus behind sticky controls, one appropriate save/error announcement, and return focus after sheets.
- iOS VoiceOver, Arabic and English: repeat supported web journeys; record installation/notification limitations honestly. Test direct entry and Back, offline startup and saved count continuity.
- Both platforms: 200% text, narrow portrait/landscape, solid/Glass, reduced transparency, high contrast and app/OS reduced motion. Verify no header tint seams, text bleed, clipped actions or obstructed focus; retain 44px targets.
- Physical Android native: notification permission refusal/grant, exact-alarm access, scheduled prayer/context reminder, app killed, reboot, battery saver/OEM policy; compare observed delivery with the selected timezone. An immediate test is not scheduled-delivery proof.
- Real lower-cost Android phone: cold online install on a constrained connection, warm online opening, offline opening, first count/rapid counts and reload durability. Record JS/transfer/cache sizes separately, and interaction-to-paint latency. Retain traces and repeated-run distributions; do not infer field p75 from a few lab runs.
- User comprehension: ask new readers to identify their next Home action within five seconds and explain local save/account sync/offline status in their own words. Record observations before changing the accepted Home hierarchy.

Field targets: LCP ≤2.5s, INP ≤200ms and CLS ≤0.1 at the 75th percentile with adequate real-device samples. Navigation metrics and screen-attributed interaction diagnostics have different scopes. Collector CLS is stored in thousandths (100 means 0.1). No current field pass is claimed.

Audio follow-up: exercise Auto-continue off/on through full prescribed repetitions and the Three Quls; optional queue/selected item/keyboard close; paused reload-resume with downloaded audio; 15-minute sleep timer in foreground/background, screen locked and device suspended; Bluetooth/headphone disconnect and interruption recovery. Verify timer suspension limitation copy, no phantom completion, sign-out/clear erasure and all controls at 320px/200%. Record exact binary/browser/device before claiming native background reliability.
