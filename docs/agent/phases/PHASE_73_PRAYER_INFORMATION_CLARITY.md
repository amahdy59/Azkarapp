# Phase Report — Phase 73: Prayer information clarity

## Objective

Make prayer information concise and readable in RTL, save space with an information icon, and place the Home reminder before the daily Wird tracker.

## Scope completed

- Native bullet points show before/after prayer guidance first, with wrapping count and rank labels.
- Longer reviewed hadith evidence and general Rawatib guidance expand through native disclosures.
- The information action remains localized, keyboard accessible, and 44×44px.
- Home visual order follows its DOM order: contextual reminder before Wird.

## Components added or modified

PrayerActionsCard and HomeScreen. No new component or dependency.

## User-visible changes

Prayer information opens to concise points; readers can expand citations. Prayer cards use an information icon. The contextual reminder appears before the Wird tracker.

## Accessibility work

Logical-start bullet indentation, explicit direction, wrapping metadata, native keyboard disclosures, named icon action, visible focus, and matching DOM/visual order.

## Tests added or updated

PrayerActionsCard tests verify icon semantics, RTL points, and collapsed evidence. Browser tests verify reminder order, RTL/LTR markers, 44px targets, disclosure keyboard activation, Escape focus restoration, and containment at 320/390/1440px.
