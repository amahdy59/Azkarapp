# Licensing and attribution

Every variant must point to an `AudioSourceRecord` with a source name and attribution. Before approval, retain durable evidence that permits the intended public hosting, streaming, offline download, caching, and redistribution behavior. A provider name or public URL alone is not licence evidence.

Do not hotlink an unversioned third-party repository or use short-lived signed URLs in the static manifest. Host immutable files behind `VITE_AUDIO_BASE_URL` with HTTPS, correct MIME types, CORS, byte ranges, public read access, and stable caching.

Required application attribution will be derived from the exact variant currently selected. Never display a reciter or voice name that differs from the served bytes.
