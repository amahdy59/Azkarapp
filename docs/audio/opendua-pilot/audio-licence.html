Scope

Worldwide, for the duration of copyright, at no charge. There is no fee, no registration, no territory limit and no need to notify us. The licence cannot be revoked once granted.

Credit

Recitation by Muhammad Jumah for OpenDua. An about screen, a credits page or a licence file all suffice.

Requested, not required

That the recitation is not presented in a way that misrepresents it. This is not a condition of the licence.

Versions
